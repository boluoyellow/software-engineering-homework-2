# 箭迹突围

一个带程序化音效、动态棋盘和弯曲路径的霓虹箭头消除闯关游戏。

## 项目结构

```text
main.py          游戏入口
game.py          状态管理、交互和界面绘制
arrow.py         箭头路径、动画与渲染
generator.py     随机自避路径关卡生成器
solver.py        阻挡关系和可解性验证
audio.py         程序化音效
levels.py        关卡难度配置
test_solver.py   自动测试与关卡验证
```

## 启动

在本文件夹打开终端：

```cmd
pip install -r requirements.txt
python main.py
```

## 玩法

- 一个箭头可以横跨多个格子；点击它覆盖的任意格都能选中整支箭头。
- 只有尖头前方没有其他箭身时才能移除；成功后整支箭会保持固定长度，像抽绳子一样依次通过自身弯道并从尖头方向离开棋盘。
- 如果前方被阻挡，箭头仍会移动到障碍物边缘，碰撞后沿原路径回弹到准确的初始位置。
- 棋盘由横竖交错、长短不一的多弯迷宫箭构成，并保留自然空隙作为箭头的移动通道。
- 点击被阻挡的箭头会扣除 1 条生命，生命耗尽后可重试当前关卡。
- 连续正确消除可累积连击和额外分数；顶部倒计时归零前需在 1 秒内完成下一次消除。
- 每关清空全部箭头后进入下一关；通关分数和进度会保留，失败重试会回到本关开始时的分数。

## 关卡系统

- 全部 10 关，棋盘每关增加 2 格，从 6×6 快速扩展到 24×24。
- 箭头数量从 4 支增加到 52 支，大地图会自动缩小单元格并保持窗口尺寸可控。
- 每支箭覆盖 4～18 格；后期仍保留较多长箭，同时用短小折线填充局部区域。
- 每支箭由随机自避路径独立生长，可形成 U 形、回钩、阶梯和不规则连续多弯，整体占用约 70%～76% 的格子。
- 空位会被用作箭头前方的疏散通道；生成顺序建立无环阻挡关系，之后再通过重叠、自交和完整求解检测。

## 视听表现

- 箭头使用 3 倍超采样绘制，带圆角路径、多层霓虹辉光、八种迷宫配色、暗色立体边和高光端点。
- 弯箭头会保持固定长度，像抽绳子一样沿完整箭身路径依次移出棋盘。
- 箭身与箭头分开绘制，窄箭身会在底边处收住，箭头保持清晰尖锐。
- 正确点击、错误碰撞、通关均有独立粒子、冲击波和震屏反馈。
- 连击提示音扩展为 16 个半音阶级：升调更平滑，整体音区和跨度也更高。
- 所有声音均由程序实时合成，不依赖外部音频文件；没有音频设备时会自动静音。
