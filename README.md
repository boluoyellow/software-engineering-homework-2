# 箭迹突围

一个带程序化音效、动态棋盘和弯曲路径的霓虹箭头消除闯关游戏。

## 项目结构

```text
main.py          游戏入口
game.py          状态管理、交互和界面绘制
arrow.py         箭头路径、动画与渲染
generator.py     随机自避路径关卡生成器
solver.py        阻挡关系和可解性验证
audio.py         程序化音效
levels.py        关卡难度配置
test_solver.py   自动测试与关卡验证
```

## 启动

在本文件夹打开终端：

```cmd
pip install -r requirements.txt
python main.py
```

## 玩法

- 点击箭头进行消除，只有前方没有阻挡的箭头才能顺利离开棋盘。
- 点错会失去生命，连续消除可以获得连击和更高分数。
- 清空棋盘上的所有箭头即可进入下一关，生命耗尽后可以重新挑战当前关卡。

## 关卡系统

- 游戏共有 10 个关卡，棋盘和箭头数量会逐渐增加。
- 箭头的长度、方向和弯曲方式随机变化，每次游玩都会生成不同且可以通关的地图。

## 游戏特色

- 使用深色霓虹风格，不同箭头有不同的颜色和弯曲形状。
- 消除、碰撞、连击和通关都有相应的动画与音效反馈。

## 测试

```cmd
python test_solver.py
```

测试覆盖棋盘密度、无重叠、箭头长度范围、弯曲路径、阻挡判定和全部关卡可解性。
