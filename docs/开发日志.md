# 《箭迹突围》开发日志

本文档根据项目文件、测试结果和实际迭代过程整理。提交记录从项目正式纳入 Git 管理之日起保存；此前过程以开发回顾的形式记录，不对历史提交日期进行补造。

## 2026-09-14：原型与核心规则

### 当日目标

- 使用 Python 与 Pygame 建立可运行的箭头消除游戏原型。
- 完成点击、阻挡判定、关卡清除和基础声音反馈。

### 完成内容

- 建立 `main.py` 游戏入口和基础窗口循环。
- 实现网格、箭头对象、鼠标选择以及箭头前方射线检测。
- 将关卡判定抽离到 `solver.py`，使用依赖关系判断地图能否完整清除。
- 使用程序实时合成点击、错误、连击和通关音效，不依赖外部音频文件。
- 加入基础霓虹背景、网格和箭头绘制。

### 遇到的问题与处理

- 单格箭头表现力不足：确定后续改为跨格连续路径。
- 随机摆放容易产生死局：加入独立求解器，在地图投入游戏前验证。
- 不同计算机可能没有可用音频设备：音频初始化失败时自动静音，避免游戏崩溃。

## 2026-09-17：完整玩法、动画与程序化关卡

### 当日目标

- 把原型扩展为具有明确难度梯度的完整闯关游戏。
- 改善弯曲箭头、移动动画、界面语言和地图丰富度。

### 完成内容

- 将箭头扩展为由多段正交线组成的连续路径，支持任意次数左右转弯。
- 重绘箭身和尖锐箭头，移除尾部圆点并加入多层霓虹辉光。
- 成功消除时让整支箭保持固定长度，沿自身路径像绳子一样抽离屏幕。
- 被阻挡的箭头会先向障碍物移动，发生碰撞反馈后沿原路径回到起点。
- 增加生命、分数、连击、1 秒连击倒计时、失败重试和通关流程。
- 界面全面中文化，并通过直接加载 Windows 中文字体解决 Pygame 字体扫描异常。
- 建立 10 关难度曲线，地图由 6×6 增长到 24×24，箭头数量由 4 支增长到 52 支。
- 单元格随地图尺寸自动缩放，后期大地图仍保持在可操作窗口范围内。
- 扩展连击音阶并减慢连续升调速度，使高连击音效更平滑。

### 地图算法迭代

1. 第一版使用规则长条完整铺满棋盘，可解但画面重复。
2. 第二版使用随机矩形分区和蛇形路径，弯曲更丰富，但仍能看出块状结构。
3. 最终版允许保留自然空位，每支箭通过随机自避路径独立生长，可形成回钩、阶梯、U 形和连续多弯。
4. 生成器按可移除顺序保留箭头前方通道，使阻挡依赖天然无环；生成后仍会执行重叠、自交和完整求解检查。

### 验证结果

- 自动测试覆盖路径转向、平滑曲线、固定长度抽离、阻挡判定和关卡求解。
- 对全部 10 关、共 200 张随机地图进行压力测试，全部可解且无箭身重叠。
- 随机地图占用率约为 56%～83%，箭头长度为 4～17 格，单支箭最多出现 13 次转弯。

## 当前状态

- 核心玩法、10 关流程、程序化地图、动画、音效和中文界面均已完成。
