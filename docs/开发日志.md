# 《箭迹突围》开发日志

## 2026-09-14

今天先把游戏的基本框架搭了起来。项目用的是 Python 和 Pygame，最开始只做了一个简单棋盘，在格子里放箭头，然后通过鼠标点击来消除。

写完最基础的点击逻辑后，我发现不能只判断箭头旁边的一格，因为箭头前方更远的位置也可能有障碍物。所以后来改成了沿箭头方向一直检查到地图边缘。地图如果完全随机生成，也很容易出现所有箭头互相挡住的情况，于是又单独写了一个求解器，在进入关卡之前先检查地图能不能清空。

今天还做了第一版音效。声音没有使用现成的音频文件，而是运行时直接生成。这样项目里不需要额外带素材，换一台电脑也能直接运行。如果电脑没有可用的音频设备，游戏会自动静音，不会因此退出。

目前原型已经能正常玩，不过箭头还比较简单，基本都是单格或直线。下一步准备做跨多个格子的弯箭头，再把界面和反馈补完整。

## 2026-09-17

今天大部分时间都花在箭头的形状和动画上。开始时弯箭头只是几个固定造型，看起来比较僵，而且飞出去的时候箭身会突然缩成一个小箭头。后来把箭头改成了一条由多段直线组成的完整路径，成功消除时整支箭会保持原来的长度，沿着自己的弯道一点点抽出去，效果更像在拉一根绳子。

错误点击也重新做了一遍。现在箭头被挡住时不会完全不动，而是先向障碍物移动，碰到以后出现红色碰撞反馈，再沿原路径退回原位。这里调了几次移动距离，不然箭头会穿过障碍物或者回不到原来的位置。

界面方面加入了生命、分数、连击和 1 秒的连击倒计时，所有文字也换成了中文。中间碰到过一次 Pygame 扫描系统字体时报错的问题，最后没有继续调用系统字体列表，而是直接读取 Windows 字体文件解决了。

关卡从 6×6 一直增加到 24×24，共 10 关。地图变大以后，单元格会自动缩小，不会让窗口无限变大。连击音效也重新调高了整体音区，并把连续升调的变化放慢了一些。

地图生成是今天改动最多的部分。第一版为了保证有解，把棋盘排成了很整齐的长条，虽然不会死局，但是看起来太规律。第二版尝试把棋盘切成一些矩形，再在矩形中生成蛇形箭头，结果还是能明显看出一块一块的结构。最后决定允许地图里出现空位，每支箭从自己的箭头位置向后随机生长，生成回钩、阶梯、U 形和连续多弯等不同路径。空位正好可以作为箭头离开的通道，画面也比完整铺满自然很多。

完成以后跑了全部关卡的自动测试，又额外生成了 200 张随机地图。测试中没有发现箭身重叠或无法清空的地图。随机地图占用率大约在 56%～83% 之间，箭头长度为 4～17 格，最多的一支箭转了 13 次弯。

现在游戏的核心玩法、动画、音效、中文界面和 10 个关卡都已经完成，暂时先做到这里。以后如果继续完善，可以考虑保存最高分、增加设置界面，或者打包成可以直接双击运行的程序。
